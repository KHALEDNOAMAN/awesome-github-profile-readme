# Contributing Guidelines

We love your input! We want to make contributing to this project as easy and transparent as possible.

## How to add a new template

1. Fork the repo and create your branch from `main`.
2. Create a new folder under `templates/` with your template name (e.g., `templates/my-awesome-template`).
3. Add a `README.md` inside your new folder containing the template code. Ensure it uses `YOUR_USERNAME` placeholders.
4. Update the main `README.md` Table of Contents to include a link and description for your new template.
5. Submit a pull request!

## Quality Standards

- Ensure all links and badges in your template work correctly.
- Use standard Markdown formatting.
- Keep the design clean and readable.
- If using external APIs/widgets, ensure they are stable and reliable.
