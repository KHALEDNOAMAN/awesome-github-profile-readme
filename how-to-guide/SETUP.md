# Step-by-Step Setup Guide

1. **Create the Repository:** Go to GitHub and create a new repository with the EXACT same name as your username.
2. **Make it Public:** Ensure the repository is public.
3. **Add a README:** Check the box to initialize the repository with a `README.md` file.
4. **Edit:** Click the pencil icon to edit the file.
5. **Copy Template:** Copy the raw code from your favorite template in this repository.
6. **Paste & Customize:** Paste it into your README. Replace `YOUR_USERNAME` and other placeholders with your info.
7. **Commit:** Commit the changes. Enjoy your awesome new profile!
