# Widgets Reference

Enhance your README with these awesome widgets:

- **GitHub Stats Card:** `https://github-readme-stats.vercel.app/api?username=YOUR_USERNAME`
- **Top Languages:** `https://github-readme-stats.vercel.app/api/top-langs/?username=YOUR_USERNAME`
- **Streak Stats:** `https://github-readme-streak-stats.herokuapp.com/?user=YOUR_USERNAME`
- **Typing SVG:** `https://readme-typing-svg.demolab.com?lines=Line1;Line2`
- **Capsule Render:** `https://capsule-render.vercel.app/api?type=waving&text=Hello`
- **Profile Views Counter:** `https://komarev.com/ghpvc/?username=YOUR_USERNAME`
